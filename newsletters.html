📧 Subscribe to Our Newsletter

Want to receive ORRA newsletters directly to your inbox? All current members are automatically subscribed using their membership email address.

Not receiving newsletters? Please contact the Secretary to update your email address.

New members: You'll be added to the mailing list when you join ORRA.

📝 How to Add a New Newsletter (Admin Guide)

Option 1: Using Google Docs (Recommended)

  1. Create Newsletter: Write your newsletter in Google Docs
  2. Publish to Web: File → Share → Publish to web → Embed
  3. Copy Embed Code: Get the iframe embed code
  4. Update This Page: Replace the iframe in the "Latest Newsletter" section
  5. Move Previous: Move the old "latest" to the archive section below

Example iframe code:

<iframe src="https://docs.google.com/document/d/YOUR_DOC_ID/pub?embedded=true" width="100%" height="800" frameborder="0"></iframe>

Option 2: Using PDF Files

  1. Create Newsletter: Design newsletter in Word/Pages/Google Docs
  2. Export as PDF: Save/export as PDF file
  3. Upload PDF: Add PDF to documents/newsletters/ folder (create if needed)
  4. Link in HTML: Add link to PDF in the newsletter card
  5. Optional: Use PDF.js or iframe to embed viewer

Example PDF link code:

<a href="documents/newsletters/2026-11.pdf" class="btn">Download Newsletter</a>

Best Practice Tips

  • Naming: Use consistent naming like 2026-11-newsletter.pdf
  • File Size: Keep PDFs under 5MB for faster loading
  • Images: Optimize images before adding to newsletters
  • Archive: Keep all old newsletters accessible
  • Email Version: Use the Google Docs link in emails, or attach PDF
  • Mobile Friendly: Test newsletter display on mobile devices
